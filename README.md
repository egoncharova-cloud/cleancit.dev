# CleanCit — главная страница

Адаптивный HTML-шаблон главной страницы CleanCit, сверстанный с нуля по макету. Проект не использует сборщик, фреймворки и внешние зависимости.

## Запуск

Откройте `index.html` напрямую в браузере или запустите любой статический сервер, например `python3 -m http.server 8000`, и перейдите на `http://localhost:8000`.

### Запуск через Docker

```bash
docker compose up --build -d
```

После запуска страница доступна по адресу `http://localhost:8080`. Остановить контейнер:

```bash
docker compose down
```

## Структура

```text
index.html
assets/
  css/main.css
  js/main.js
  images/
    logo.svg
    icons/sprite.svg
    hero/hero.webp
    services/*.webp
    cta/employee-transparent.png
```

- `index.html` — семантическая разметка всех компонентов.
- `main.css` — переменные дизайн-системы, компоненты, сетки и адаптив.
- `main.js` — доступное мобильное меню и текущий год в footer.
- `sprite.svg` — единый набор outline-иконок.

## Компоненты

Header, hero, сетка карточек услуг, преимущества, этапы работы, CTA и footer разделены BEM-классами. Карточки услуг, элементы преимуществ и шаги имеют одинаковую повторяемую структуру, пригодную для циклического вывода.

## Изображения

Все фотографии сгенерированы специально для шаблона, не содержат внешних логотипов и хранятся локально в WebP: hero, аренда и обслуживание кабин, парогенератор, илосос, доставка воды, выгребная яма, септик, прочистка канализации и сотрудник CTA. Hero загружается приоритетно, остальные изображения используют `loading="lazy"`.

## Адаптив

- Desktop: от 1200 px — четыре карточки услуг, горизонтальные преимущества и этапы.
- Laptop/tablet: до 1100 px — две карточки, упрощенная навигация и сетки.
- Mobile: до 767 px — burger-меню, одна колонка услуг, вертикальные этапы.
- Small mobile: до 480 px — полноширинные кнопки и упрощенный footer.

Компоненты дополнительно адаптируются между точками за счет Grid/Flexbox, `minmax()` и `clamp()`.

## Рекомендации для интеграции в UMI.CMS

- **Header:** вынести в общий шаблон; сделать управляемыми логотип, главное меню, телефон и кнопку.
- **Footer:** вынести в общий шаблон; получать меню, соцсети, реквизиты, контакты и юридические ссылки из CMS.
- **Меню:** выводить стандартным механизмом иерархии UMI, сохраняя текущие классы ссылок и контейнеров.
- **Услуги:** создать коллекцию/раздел с полями `title`, `description`, `image`, `icon`, `url`; выводить карточки циклом.
- **Преимущества:** управлять заголовком, описанием и идентификатором иконки каждого элемента.
- **Этапы работы:** хранить номер, название, описание и иконку; порядок задавать сортировкой CMS.
- **Контактные данные:** телефон, email, адрес и подпись о бесплатном звонке вынести в общие настройки сайта.
- **CTA:** сделать редактируемыми заголовок, описание, подпись/ссылку кнопки, изображение сотрудника и список преимуществ.

При интеграции пути изображений заменяются значениями полей UMI.CMS. Основной контент не зависит от JavaScript; при отключенном JS недоступно только раскрытие мобильного меню и автоматическая подстановка года.
